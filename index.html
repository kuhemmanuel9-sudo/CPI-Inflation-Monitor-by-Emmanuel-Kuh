Analytics Methodology

Transparent calculations designed to make CPI trends, category differences, and recent inflation dynamics easier to interpret.

Data source The dashboard requests 18 CPI-U series across unadjusted and seasonally adjusted versions, staying below BLS public API request limits while labeling fallback data clearly.
Year-over-year inflation Calculated as the latest index divided by the same month one year earlier, minus one, then expressed as a percent.
Monthly movement Calculated from seasonally adjusted CPI series where available. This avoids presenting ordinary seasonal patterns as short-term inflation dynamics.
CPI Pressure Index An experimental dashboard-specific indicator from headline inflation, seasonally adjusted monthly speed, broad category movement, and recent volatility. It is not an official BLS measure.
